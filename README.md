# Финансовый учёт проектов

Веб-приложение для ручного учёта доходов и расходов по проектам. Разработано для экосистемы **Битрикс24**. Позволяет оценивать экономическую эффективность каждого проекта: видеть доходы, расходы, прибыль и рентабельность.

---

## Функциональность

- **Управление проектами** – создание, редактирование, удаление проектов. При создании указывается руководитель.
- **Доходы и расходы** – добавление операций с привязкой к проекту и статьям (можно добавлять свои статьи).
- **Синхронизация** – выбор проекта синхронизируется между всеми вкладками (доходы, расходы, фильтр, графики).
- **Автоматические расчёты** – прибыль и рентабельность считаются автоматически.
- **Дашборд** – сводка по проектам в виде карточек (виден 1 ряд, остальные под скроллом).
- **Итоги за текущий месяц** – суммарные доходы, расходы и прибыль по всем проектам.
- **Графики**:
  - Гистограмма динамики доходов и расходов по месяцам.
  - Круговые диаграммы распределения по статьям (доходы и расходы).
- **Экспорт в Excel** – выгрузка данных по проектам, доходам и расходам в один `.xlsx`-файл (3 листа).
- **Резервное копирование** – экспорт и импорт данных в JSON.
- **Хранение** – все данные сохраняются в `localStorage` браузера (не требуют сервера).
